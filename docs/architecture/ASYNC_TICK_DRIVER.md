# Async tick composition (#77)
AsyncTickDriver combines TickScheduler, CommittedWorld and the existing engine. One tick in flight, publication only after acknowledgement, busy pulses skipped, no catch-up burst; fault stops new ticks and retains committed state. Explicit drain supports lifecycle coordination. Integration test uses real PersistenceWorker and compares eight empty-world ticks with synchronous engine plus restart recovery. This is an experimental composition harness, not enabled in makePrototype. Remaining gate: unify admin mutations, read RPC, timeline/clock, bootstrap and shutdown in one async server factory; test with populated worlds, concurrent HTTP/WS and fault injection. No production TPS or durability policy changes. Busy pulses reduce effective TPS; benchmark before activation. Scheduler observers are not registered by this driver.
