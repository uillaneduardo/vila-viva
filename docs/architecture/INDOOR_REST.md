# Deadwood and indoor rest
Dead/old apple tree cutting accepts same-cell or adjacent actors and produces existing 3–5 wood ground drop; removes tree independent of inventory space. Deadwood maintenance precedes ordinary affinity work but not survival/urgent delivery/pickup. Indoor rest uses optional sleepingInId on a reserved completed house; exterior position remains reserved as safe exit, no physical six-bed overlap on four-cell footprint. Renderer hides indoor sleepers in all modes; inspector exposes house ID. Release on wake, hunger, movement, destruction, death/expiry through existing bed lifecycle. Existing saves without field remain valid; next rest decision enters. Limitation: exterior entrance remains occupied while sleeping, no full interior or entry animation.
