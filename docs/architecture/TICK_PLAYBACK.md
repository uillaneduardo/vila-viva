# Tick playback adapter — #59
Default composition uses createTickRenderAdapter(surface); ?renderer=legacy selects the original Scene interpolation. The playback module imports no domain, engine, transport, DOM or persistence. Scene owns drawing, camera and sprite registry; the injected position provider supplies interpolated confirmed positions for draw/pick. Brush validation still uses authoritative grid. Sprite states remain registry-driven; future animation adapters consume activity, visual position/velocity, death and phase, never invent gameplay. No new art assets.
Gateway uses explicit publication after committed ticks and accepted commands/clock/world changes, including paused changes. Existing projection and delta wire remain backward-compatible, with optional monotonic sampleTime, epoch and revision; initial snapshot/resync remains authoritative. Bounded volatile ring (64 packets / 2 MiB), not replay storage. Reconnect gets current snapshot, not queued stale packets. 1x/2x/4x nominal logical rate preserved (4/8/16 ticks/s) by spacing each tick on a 62.5 ms scheduler quantum instead of batches; no catch-up under overload. The original synchronous durable commit remains before publication; do not silently weaken durability. Isolating durable I/O and full projection optimization are follow-ups #27/#57. No claim of latency or FPS until browser/homelab profiling.
Playback buffer max 32 samples; initial delay one nominal tick (250/125/62.5ms), increased for observed jitter, capped at 1s. No extrapolation, snap on non-adjacent displacement, pause, timeline or speed transition. Reconnect clears playback but preserves selection in same timeline. HUD coalesced to 250ms while moving; inspector remains separate. Full entity state is still needed for current UI; specialized minimal visual projection and asynchronous diagnostics remain follow-ups.
Tests cover buffer bounds, timing at 1/2/4x, pause/epoch/teleport, injected adapter. Existing stream and persistence regression suites remain required. Browser QA and live deployment measurements remain explicit gates.
