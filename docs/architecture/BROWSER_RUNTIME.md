# Browser runtime experiment

/browser reuses the current authoritative engine in a dedicated Web Worker. Static bundle compiled with esbuild in Docker; existing / and /admin unchanged. No simulation HTTP or WebSocket calls. Clock uses existing scheduler (4 TPS at 1x). Same seeded world, catalog, inspection, brush and commands. Local saves are session-memory only, export/import JSON for persistence; journal bounded to 5000 action ticks. No automatic server synchronization, no authority migration, no persistence after tab close. Browser background throttling applies. Goal: compare visual and simulation costs, not claim zero processing latency. Validate with browser devtools offline after assets loaded, pause/speed, brush, export/import, server world unchanged, frame pacing.
